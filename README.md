# sales-skills

Claude Code 플러그인 마켓플레이스.

## 설치

```
/plugin marketplace add heonq/sales-skills-marketplace
/plugin install sales-weekly-report@sales-skills
```

## 플러그인

| 이름 | 설명 |
|------|------|
| `sales-weekly-report` | 판매관리.xlsx → `N월 M주차.xlsx` 주간 리포트 생성 (요약·판매분석·재고현황·액션아이템). Python 3 + `openpyxl` 필요, 수식 재계산엔 LibreOffice 사용. |
